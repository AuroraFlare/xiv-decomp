- `SEQ_000` starts at Hedyn in Ul’dah and the core pre-instance sequence.

### State and gates

- Sequence transitions are tied to `onTalk`, `onPush`, and cutscene completion; the script also publishes marker changes per phase.

### QuestDirectorEventMan30401 behavior
- The director drives a small objective script in private Waking Sands copy:
- It sets up initial companion replacement and scene progression in `onCreateContentArea` and `main`.
- It keeps the player and companion on track during instance lifecycle.
- It includes recovery hooks so if private state desyncs, player can re-enter quest flow cleanly.

### Director-specific implementation notes

  - `man30400` opening, `man30410` soil ritual handoff, `man30420` post-instance path assembly, `man30430` return.
- The director supports recovery if player exits before completion and re-enters through the same quest copy.
- There is an explicit “reward target on interruption” route so Minfilia remains contactable if progress was completed and the final cinematic path is lost.

### Rewards
- `scenarioHelpers.completeQuest` is used at the final branch.
- Final payout mirrors client script: gil and XP, plus progression unlock for next `man308` node.

### Optional text coverage
- Required progression lines and branch events are connected.
- Optional ambient entries are larger than required surface; they are not all clickable in ENPC routing in this implementation.

## 110017 — Lord Errant (`man308` / 110017)

### Sources
- [man308.lua](/C:/Users/drime/source/repos/AuroraFlare/FF14-Memory/Data/scripts/quests/man/man308.lua)
- [QuestDirectorMan30801.lua](/C:/Users/drime/source/repos/AuroraFlare/FF14-Memory/Data/scripts/directors/Quest/QuestDirectorMan30801.lua)
- [SimpleContentMan30801.lua](/C:/Users/drime/source/repos/AuroraFlare/FF14-Memory/Data/scripts/content/SimpleContentMan30801.lua)

### Sequence contract
- `SEQ_ACCEPT` -> `SEQ_000`: open in Silverlance/market path and gate to Paglthian gate.
- `SEQ_000` -> `SEQ_005`: approach trigger.
- `SEQ_005` -> `SEQ_010`: content launch.
- `SEQ_010` -> `SEQ_015`: ritual and parley state.
- `SEQ_015` -> `SEQ_020`: combat completion and reward exit.
- `SEQ_020` rewards at Minfilia and returns to Waking Sands.

### Entry and map transitions
- Content is created with:
  - Zone `174`
  - Private area container `SimpleContentMan30801`
  - Director `Quest/QuestDirectorMan30801`
  - `CreateContentArea` then `DoZoneChangeContent` to `(995.168, 309.146, 982.116, -2.519)`.
- Boundary is set to `970, 950, 1035, 1015`.
- Sequence transitions:
  - `SEQ_010`: companion talk can call `advanceMan308RitualFromCompanion`.
  - `SEQ_015`: one parley success or direct recovery route enters combat.

### Director internals (`QuestDirectorMan30801`)
- Script constants:
  - `TIMEOUT_SECONDS = 1800`
  - `LANDING_DELAY_SECONDS = 2`
  - `FIGHT_LEVEL = 38`
  - `ENEMY_HP = 2500`
  - `EVENT_TIMEOUT_SECONDS = 8`
  - `MINEMITE` equivalent in this quest is the Amjal’aa triad.
- Captive negotiation:
  - Captives are spawned with `SetTempVar` keys (`negotiation.enabled`, title/item/turn params) and are visible only in ritual state.
  - Prefix key for captives: `man308_captive_*`.
  - `onNegotiationResult` sets `MAN308_FLAG_PARLEY_COMPLETE` on success and transitions to combat spawn.
- Combat phase:
  - Allies: Path companion swapped to ally with high durability (3200 HP), ally is added to claim party.
  - Enemies: three Amjal’aa with BNPC IDs 32712/32713/32714 and actor classes `2206508/2206512/2206518`.
  - `startCombat` removes captives, spawns combatants, starts content group, and notifies via system message.
- Completion:
  - Kill-count polling in director (`countDefeated`) is authoritative.
  - On kill total, director queues `COMPLETION_EVENT_ARG` and falls back direct completion if event callback stalls.
  - `completeBattlefield` runs `pE80`, updates sequence, cleans actors, and warps to return point `1217.650, 311.707, 776.001`.
- Failure states:
  - Player death, leaving battlefield, missing player/quest, spawn failures, route timeouts.
  - On fail, sequence resets to `SEQ_005`, flag `MAN308_FLAG_PARLEY_COMPLETE` is cleared, and player is warped to public Paglthan point.
- Recovery content hook:
  - [SimpleContentMan30801.lua](/C:/Users/drime/source/repos/AuroraFlare/FF14-Memory/Data/scripts/content/SimpleContentMan30801.lua) handles player leaving in `SEQ_010`/`SEQ_015` by clearing flag `0` and restoring `SEQ_005`.

### Cutscenes and dialogue wiring
- `pE10` (entry), `pE20/pE30` (companion ritual movement), `pE50/pE60` (parley/captive), `pE80` (battle clear), `pE90` (final Minfilia scene).
- Quest reward branch delegates `pE90` and standard reward window via quest reward helpers.

## 110019 — Futures Perfect (`man406` / 110019)

### Sources

### Sequence contract
- `SEQ_ACCEPT` from Minfilia with seven briefing NPCs in Waking Sands.
- `SEQ_000` records briefing count via flags `0..6`.
- `SEQ_005` transitions to Revenant’s Toll content.
- `SEQ_010` is pursuit/combat setup in private area.
- `SEQ_015` is post-attempt completion/reentry state.
- `SEQ_020` is cave aftermath (`man406` children + cave trigger).
- `SEQ_025` is Tataru report and reward.

### Enter/entry architecture
- Content is created with party support through:
  - `CreateContentAreaForAllDisciplines`
  - `MAN406_CONTENT_AREA_PATH = /Area/PrivateArea/Content/PrivateAreaMasterSimpleContent`
  - `MAN406_CONTENT_PRIVATE_AREA = SimpleContentMan40601`
  - `Quest/QuestDirectorMan40601`
  - Zone `190`
- Party entrants are gathered by `GetPartyMembersInRange(40)` with max 3 entrants.
- `SetQuestReentryPolicy` is called for the content area when supported.
- Entry defaults to `(-218.470, 18.542, -666.627, -2.817)` (or cave recovery position when testing post-combat).
- Quest marker and ENPC state are rebuilt via normal `quest:SetENpc` on each state transition.

### Director internals (`QuestDirectorMan40601`)
- Script constants:
  - `TIMEOUT_SECONDS = 2700`
  - `LANDING_DELAY_SECONDS = 3`
  - `FIGHT_LEVEL = 50`
  - `EVENT_TIMEOUT_SECONDS = 8`
- Event routing:
  - `OPENING_EVENT_ARG = "imperialsWithdraw"`
  - `ARRIVAL_EVENT_ARG = "imperialsCornered"`
  - `COMPLETION_EVENT_ARG = "battleWon"`
  - All are received through `onEventStarted` as `noticeEvent`.
- Pursuit flow:
  - Route key `futures_perfect_imperial_pursuit`
  - If not flagged, director queues opening, then starts route.
  - On escort route complete, queues ARRIVAL event and begins combat.
  - Route failure, deleted escort director, or pursuit loss triggers fail.
- Combat flow:
  - Spawns 4 combatants: Juggernaut, Centurion, Hoplomachus, Sagittarius with explicit HPs `14874, 6200, 5600, 4800`.
  - All are set to level 50 with DPS AI and quest fight caps.
  - Kill progress is polled via unique IDs and actor alive checks.
  - Completion queues completion event and fallback direct completion.
- Completion/cave transition:
  - `completeBattlefield` delegates `pE30`, sets `SEQ_020`, spawns cave aftermath actors:
    - 5 children (`man406_*_child`), and trigger `man406_cave_vision_trigger`.
  - Then moves each entrant to cave coordinates `265.470, 56.408, -799.867`.
- Cave phase:
  - In `SEQ_020`, each child ID maps to `processEvent045_1..5`.
  - Cave trigger pushes `pE50` through `finishMan406CaveVision`, sets `SEQ_025`, and returns to public `(173.430, 18.700, -641.260, 2.200)`.

### Failure + recovery
- `failBattlefield` clears `MAN406_FLAG_PURSUIT_COMPLETE`, restores `SEQ_015`, and warps all entrants out with public return message.
- Common fail cases: player defeat, route failure, leaving battlefield, missing quest, missing combat/cave spawns, generic timeout.
- `SimpleContentMan40601.lua` re-saves ENPC state on player leave in `SEQ_015` and `SEQ_020`.

### Rewards and finish behavior
- `SEQ_025` reward path triggers `pE60`, rewards `[46000, 1, 1, 2]`, then `completeQuest`.
- `onFinish` does custom mount award: `IssueGoobbue()` when not already owned.

## Cross-quest recovery patterns observed
- 110017/018/019 all use private-area director fail/re-entry recovery with content hooks.
- 110017 and 110018 use content-side `onPlayerLeft` scripts to persist/repair quest state on unexpected exit.
- 110016 includes an explicit recovery target in content flow if completion cutscene is interrupted.
- All three later quests validate content entry through `checkCombatInstanceEntry` / `guardCombatInstanceEntry` depending on route start path.
- All major completion transitions are event-driven with 8-second fallback windows in directors to recover from missing event callbacks.

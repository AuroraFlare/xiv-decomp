## Short Version

Both local quest files are still hidden generic scaffolds, but they now expose probe metadata/constants and helper accessors before calling `InitQuestScaffold`. The recovered scenario scripts are useful for cutscenes, talk rows, SNPC argument shapes, and replay probes, but the recovered directors are empty subclasses of `QuestDirectorBaseClass`. That means there is still no route authority for offer timing, objective sequencing, battle spawns, scout protection, operation failure state, reward grant, or instance cleanup.

Safe work in this pass:

- Added shared helpers for quest id reads, quest completion replay flags, SNPC replay sexuality-skin payloads, and main-scenario SNPC preview scene lookup.
- Documented `Man402` cutscene and talk helpers, including the accepted-offer `man40200` path and the field `man40210/20/30` scene trio.
- Documented `Man406` scene chain, including the bundled `pE30` triple scene and the scaffold-only `processEvent025` hook.
- Added local probe metadata/accessors for `Man402` and `Man406`, plus a passive `QuestObjectMan402` object script.
- Captured reward-risk and replay anomalies so these quests stay hidden until runtime sequence proof exists.

Do not wire completion, rewards, bloodhound/scout objectives, Ala Mhigan Resistance battle content, or after-warp sequence advancement yet.

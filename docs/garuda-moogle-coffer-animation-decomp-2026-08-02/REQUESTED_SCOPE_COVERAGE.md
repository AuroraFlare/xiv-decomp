# Requested-scope coverage matrix

Generated: 2026-08-02

This matrix accounts for the requested Garuda, Good King Moggle Mog XII, and giant non-guildleve coffer surfaces. It is an index of findings, not an implementation plan. All work was read-only; no game, server, client, source, SQL, script, model, effect, animation, actor, or spawn data was changed.

## Status key

- **Proven**: directly decoded from the installed client or directly traced through the pinned current server/source. The evidence column identifies which.
- **High-confidence**: strongly supported by names, curves, timing, structure, or consistent joins, but lacks an authoritative retail selector/packet trace.
- **Unresolved**: no exact retail mapping or concrete join was recovered.
- **Excluded**: intentionally outside the requested target and used only as a comparison/control.

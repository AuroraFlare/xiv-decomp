## Extractor Rules

The extractor follows the helper recommendation:

- Preserve recovered file order as `method_order`; do not sort by numeric suffix.
- Emit one spine row per `function Class.method(...)`.
- Emit one call row for normalized colon calls and decompiler alias calls such as `L12 = A0.startNQCutScene; L12(A0, ...)`.
- Treat `showQuestInfomation`, job item widgets, reward widgets, `changeItem`, item helpers, quest accept/complete, and EXP as mutation evidence, not proof of server mutation.
- Leave generic owners unresolved unless another source supports them. Generic names include `NQ`, numeric steps, and elevator helpers.

## CSV Meaning

`quest_method_spine.csv` columns capture:

| Column | Meaning |
| --- | --- |
| `method_order` | Recovered file order for the method. |
| `cutscene_ids` | Distinct cutscene IDs called by the method. |
| `ask_rows` | Distinct ask/widget row IDs seen in the method. |
| `after_warp` | Method calls `startFadeInCutSceneAfterWarp`. |
| `mutation_families` | Risk evidence such as quest offer, reward widget, item change, or EXP. |
| `owner_hint` | Method-name, receiver-arg, or atlas-derived owner hint. |
| `no_mutation_policy` | Set for current blockers and sequence-spine quests. |

`quest_method_calls.csv` is the drill-down table: line, receiver, callee, raw args, normalized args, call family, cutscene ID, ask row, and return/branch role.

# Patch 1.18b


**Source:** https://forum.square-enix.com/ffxiv/threads/20351-patch1.18b-Patch-1.18b-Notes%7C

> **Battle**
> * [dev1129] The following adjustments will be made to the penalty to gear condition upon being KO’d.
> * Rank 1–9　 　Gear condition will not be damaged.
> * Rank 10–19　The damage to gear condition will be reduced to half the current amount.
> * Rank 20–　   Gear condition will continue to suffer the same damage it has in the past.

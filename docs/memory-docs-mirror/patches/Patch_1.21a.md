# Patch 1.21a


**Source:** https://forum.square-enix.com/ffxiv/threads/40824-patch1.21a-Patch-1.21a-Notes%7C

> **Event**
> * [dev1345] Players can now redistribute attribute points. To do so, speak with the guild NPC in charge of exchanging guild marks while in possession of a copy of the Keeper's Hymn. You will be given the option to undo point allotment for your current class in exchange for the item.

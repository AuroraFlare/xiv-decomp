> **Bug Fixes**
> * The following known issues have been addressed:
> * An issue wherein the placement of high level enemies rendered it difficult to complete the quest “Forever Taken.”
> * An issue wherein the quest “To Deskunk a Beer” could not be completed.
> * An issue wherein the reward items were incorrect for the local levequests “A Spot in the Shade” and “Running Rings.”
> * An issue wherein leve history was not being evaluated as intended.
> * An issue wherein Guardian’s favor would not be distributed for players who undertake company leves exclusively.
> * An issue wherein the bazaar modeling feature would allow male retainers to wear female-only gear, and vice versa.
> * An issue wherein materia-enhanced gear could be delivered for guild tasks.
> * An issue wherein deliveries could be made for supply and provisioning missions even if the items were no longer accepted.
> * An issue wherein the amount of company seals required for promotion to Private Second Class was being erroneously displayed as 100.
> * An issue wherein bazaars for seeking items and repairs would not indicate the quantity of the item offered as a reward.
> * An issue wherein the blacksmithing recipe for synthesizing bronze ingots, iron ingots, or steel ingots would yield white quartz instead of a high-quality item when a secondary tool is used.
> * An issue wherein the goldsmithing synthesis level for electrum ingots and mythril ingots was incorrect.
> * An issue wherein targeting would be canceled when attempting to select a party member on the party interface who is not nearby.
> * An issue wherein the configuration data of the last character with which you logged in would be transferred to that of a newly created character.

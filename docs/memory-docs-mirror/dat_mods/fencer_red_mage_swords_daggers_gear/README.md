# Fencer Red-Mage Sword/Dagger and Gear Overlays

Generated by `tools/fencer/build_fencer_swords_daggers_gear.py`.

This folder intentionally does not overwrite any live client DAT files. It stages row overlays in the same style as `docs/dat_mods/job_gear_weapon_overlay_runbook.md`, plus a server SQL update:

- `dat_overlays/data/01/03/05/89.DAT/itemData.rows.csv`: staged `itemData` row overlay input.
- `dat_overlays/source_sheets/*.rows.csv`: extracted-sheet overlays for `weapon`, `equipment`, `_item`, `xtx_itemName`, and `compatibility`.
- `manifest/fencer_sword_dagger_weapon_clones.csv`: 12 new Fencer sword/dagger clones in the shared `5040001+` Arcanist placeholder-backed range.
- `manifest/pugilist_mage_gear_compat_updates.csv`: 872 existing non-weapon Pugilist/mage-friendly gear rows remapped to Fencer-inclusive compatibility rows.
- `manifest/af_job_identity_exclusions.csv`: 2 AF/job-identity rows intentionally skipped.
- `manifest/compatibility_rows.csv`: 21 new compatibility rows.
- `../../../Data/sql/custom content/Custom Equipment/fencer_red_mage_swords_daggers_gear.sql`: server-side implementation SQL.

## Weapon Ladder

The new weapons keep Gladiator sword/dagger visuals and item kind `5006` because the mined 1.0 text sheets do not contain a Fencer's Arm item-kind row. Their behavior-facing fields are Fencer/Fencing: `mainSkill = 5` and the Fencer-only weapon compatibility row `2186`.

Weapon damage stats are copied from nearby Lancer weapons and scaled to 72% damage power. Equipment bonus values from the Lancer donors are scaled to 70%, so the weapons lean Lancer-like without landing at full polearm strength. Each generated Fencer weapon uses equip point 36 and frequency 1, making it an independent weapon that can occupy either arm under the shared dual-wield policy.

## Gear Compatibility

All-jobs gear already uses compatibility row `1`, which includes Fencer, so the package does not rewrite all-jobs gear. The generated update only remaps Pugilist-, Thaumaturge-, or Conjurer-compatible non-weapon gear whose compatibility row leaves Fencer below that eligibility value.

The compatibility rows are union-aware with the earlier custom packages: Pugilist-derived rows also keep Assassin eligibility, and mage-derived rows also keep Arcanist eligibility, so loading this package after those overlays will not strip those custom jobs back off shared gear.

AF and job-identity gear is deliberately excluded by name marker, including `temple`, `fighter's`, `gallant`, `drachen`, `choral`, `evoker's`, `warlock's`, `cleric's`, `duelist's`, and relic-style weapon names. Current mined Pugilist/mage gear produced 2 such exclusions.

Client-side display still needs the DAT overlays applied or rebuilt. Server-side equip behavior is covered by the generated SQL.

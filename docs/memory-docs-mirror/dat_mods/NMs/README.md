## Retail stat overrides

These rows intentionally update the named retail item instead of creating a
new catalog item. The override remains isolated to the NMs overlay and its SQL.

| Catalog ID | Item | Defense | Parameters |
| ---: | --- | ---: | --- |
| `8013601` | Darklight Helm | `94` | `15018` = `20`, `15051` = `4`, `15004` = `15`, `15087` = `5`, `15025` = `-20` |

The two belts use native `809xxxx` placeholders, the two body pieces use
native `803xxxx` placeholders, the hand gear uses native `807xxxx` rows,
the footwear uses native `808xxxx` rows, and Ebon Slacks, Lore Kecks, and
Black Slacks use native `805xxxx` leg placeholders. Master Earrings uses the final unused native `903xxxx`
earring placeholder. Materia Earrings extends that
contiguous earring range to `9030066`. Celer Ring and Bronic Ring
extend the contiguous native `905xxxx` ring range to `9050082-9050083`
because that family has no unused placeholder rows. The three custom wrist
items extend the contiguous native `901xxxx` wrist range to `9010065-9010067`.
Ahmar Turban extends the native head range to `8013638`. Named retail
sources are visual/metadata donors and remain untouched except for the explicit
Darklight Helm stat override documented above.

All custom rings, earrings, and wrist items are explicitly rare/exclusive
with `materiaBindPermission = false`, making them unique, untradeable, and
not meldable. The belts, body pieces, hand gear, footwear, and leg gear have
rare/exclusive disabled and `materiaBindPermission = true`, making them
tradeable and eligible for player materia melding. Existing source compatibility is kept
for the belts. Connexus's Robe, Healing Mitts, and Connexus's Crakows use
retail Discipline of Magic row `2005`; Malum's Scale Mail, Fingerless Ashen
Gloves, and Malum's Moccasins use Discipline of War row `2004`. The rings and
both earring items use all-classes/jobs row `1001`. Row `2004` includes both the base DoW
classes and their job forms; row `2005` does the same for DoM classes/jobs.
Bronic Ring uses exact compatibility row `2101`, which enables only Gladiator,
Marauder, Paladin, and Warrior.
Silver Wristlets uses Discipline of Magic row `2005`. Twilight Wristguards
uses exact compatibility row `2133`, which enables only Archer and Bard.
Ebon Slacks uses custom compatibility row `2207`, which enables
only Pugilist, Archer, Lancer, Monk, Bard, and Dragoon. IDs `2159-2206` remain
reserved for the existing custom job overlays.
Lore Kecks preserves Felt Kecks (Blue)'s compatibility row `2104`; Black
Slacks preserves Dated Velveteen Kecks (Black)'s all-classes/jobs row `1001`.

The stock client parameters `15055` and `15056` are blank. The NMs overlay
labels them `Damage Taken` and `Magic Damage Taken`; the server maps their
signed tooltip values to positive reduction modifiers.

Parameter `15085` is another unused client row. The overlay labels it
`Melding Tier Chances`; the server treats it as a percentage-point increase
to the highest materia tier allowed by the converted item's level. Materia
Earrings also uses the stock functional `15058` Increased Spiritbond Gain.
Parameter `15086` is labeled `All Elemental Resistance`; the server expands
its value into Fire, Ice, Wind, Earth, Lightning, and Water resistance.
Parameter `15087` is labeled `Double Attack`; its value is a percentage-point
chance for an auto-attack round to gain one immediate extra hit, capped at
three total hits. The extra hit resolves in the same battle command and does
not add another weapon-delay interval.

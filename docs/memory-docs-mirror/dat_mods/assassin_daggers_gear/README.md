# Assassin Dagger and Pugilist Gear Overlays

Generated by `tools/assassin/build_assassin_daggers_gear.py`.

This folder intentionally does not overwrite any live client DAT files. It stages row overlays in the same style as `docs/dat_mods/job_gear_weapon_overlay_runbook.md`, plus a server SQL update:

- `dat_overlays/data/01/03/05/89.DAT/itemData.rows.csv`: staged `itemData` row overlay input.
- `dat_overlays/source_sheets/*.rows.csv`: extracted-sheet overlays for `weapon`, `equipment`, `_item`, `xtx_itemName`, and `compatibility`.
- `manifest/assassin_dagger_weapon_clones.csv`: 21 new Assassin dagger/short-sword clones in the shared `5040001+` placeholder-backed range.
- `manifest/pugilist_gear_compat_updates.csv`: 443 existing non-weapon Pugilist-friendly gear rows remapped to Assassin-inclusive compatibility rows.
- `manifest/af_job_identity_exclusions.csv`: 0 AF/job-identity rows intentionally skipped.
- `manifest/compatibility_rows.csv`: 12 new compatibility rows.
- `../../../Data/sql/custom content/Custom Classes/assassin/30_assassin_weapons.sql`: server-side implementation SQL.

## Weapon Ladder

The new weapons keep authentic Gladiator dagger, short-sword, primal, Moogle, and Skirmish visuals and item kind `5006` because the mined 1.0 text sheets do not contain an Assassin's Arm item-kind row. Their behavior-facing fields are Assassin/Dark Arts: `mainSkill = 13` and the Assassin-only weapon compatibility row `2174`.

Damage, delay, damage type, and equipment bonuses are copied from each weapon's actual 1.0 source row. Assassin weapons are main-hand-only because the 1.x client T-poses when an Assassin dagger is placed in the secondary arm. Triple Attack supplies multi-hit rounds without entering that unsupported client state.

The four recovered special models retain their FF14 identity: `Morbid Mogblade`, `Ifrit's Blade`, `Garuda's Gaze`, and the Skirmish `Giantsgall Longsword` model renamed `Giantsgall Short Sword` for Assassin. Their `Augmented` variants are level-50 Rare/Ex upgrades with 8% more weapon damage; `Augmented Mailbreaker` gains 10%. No Assassin weapon or augmentation recipe is active in crafting; five commented-out recipe templates remain in the SQL for possible future use. Special and augmented weapons are intended for loot, quest, or exchange acquisition.

Ordinary and Rare-only Assassin weapons explicitly enable the DAT-backed materia binding permission. Rare/Ex weapons—including Moogle, primal, and every augmented weapon—explicitly disable materia melding.

## Gear Compatibility

All-jobs gear already uses compatibility row `1`, which includes Assassin, so the package does not rewrite all-jobs gear. The generated update only remaps Pugilist-compatible non-weapon gear whose compatibility row leaves Assassin at `0`.

AF and job-identity gear is deliberately excluded by name marker, including `temple`, `fighter's`, `gallant`, `drachen`, `choral`, `evoker's`, `warlock's`, `cleric's`, and relic-style weapon names. Current mined Pugilist gear produced 0 such exclusions.

Client-side display still needs the DAT overlays applied or rebuilt. Server-side equip behavior is covered by the generated SQL.

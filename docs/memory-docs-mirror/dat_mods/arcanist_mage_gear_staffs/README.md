# Arcanist Mage Gear and Staff Overlays

Generated by `tools/arcanist/build_arcanist_mage_gear_staffs.py`.

This folder intentionally does not overwrite any live client DAT files. It stages row overlays in the same shape they would need for a client-side DAT rebuild, plus a server SQL update:

- `dat_overlays/data/01/03/05/89.DAT/itemData.rows.csv`: staged `itemData` row overlay input.
- `dat_overlays/source_sheets/*.rows.csv`: extracted-sheet overlays for `weapon`, `equipment`, `_item`, `xtx_itemName`, and `compatibility`.
- `tools/arcanist/patch_arcanist_mage_gear_dats.py`: writes the live overlay DAT package, including the English `xtx_itemName` triple at `data/0B/45/03/66.DAT`, `67.DAT`, and `68.DAT`.
- `manifest/arcanist_weapon_clones.csv`: 143 new ACN staff/scepter/wand/cane clones in the compact `5040002+` ACN weapon range.
- `manifest/caster_gear_compat_updates.csv`: 483 existing non-weapon caster-friendly gear rows remapped to ACN-inclusive compatibility rows.
- `manifest/compatibility_rows.csv`: 14 new compatibility rows.
- `../../../Data/sql/custom content/Custom Equipment/arcanist_mage_gear_staffs.sql`: server-side implementation SQL.

The weapon clones copy the source icon, graphics, level, stats, repair data, stack flags, and equipment/weapon rows. Their player-facing English names are changed to a more Final Fantasy-flavored ACN staff naming style; the class/kind/compatibility fields are changed only so the server and client treat them as Arcanist arms.

No placeholder item rows are reused. The existing `5040001` placeholder stays untouched.

## Takeaways

- Man300 text explicitly offers a non-violent route: speak with the shamans, play the tiles, and best them at Parley.
- The recovered client gate for target-side Parley is `isPropertyEnabled(4)`. Local actor classes in the Amalj'aa/Ixali neighborhood commonly carry `propertyFlags = 23`, which includes bit 4.
- The local Man300 script currently names `BNPC_AMALJAA_GRUNT = 2106537` and `BNPC_IXALI_WARRIOR = 2106408`. Those are better treated as combat-route actors until packet/runtime evidence proves they are also the Parley targets.
- Better Parley target candidates exist beside them: Amalj'aa shaman/thaumaturge classes such as `2106522`, and 22065xx shaman display classes. Ixali caster candidates show up as fatecaller/fearcaller ambient cohorts, but Man300 has not yet bound them locally.
- The remaining hard gap is still runtime: capture command `29497` against the Man300 SEQ_030 target to learn the EventStart payload and negotiation table/topic id.

# Natalan population — 2026-09-12

Natalan in **Coerthas Central Highlands, zone 143**, now has **91 authored
public-world enemies** in the project SQL. This includes the common troops,
four sentry jobs, Scarred Watchwolf, **Lozol Totoloq the Decapitator** and **two
Headsman's Axe guards**. The existing 257 public Highland placements and all
quest/guildleve layouts are preserved. No database import, server restart or
in-game collision/roaming test was performed.

The [interactive review](maps/natalan-20260912/index.html) shows the recorded
ground, captured edges, role filters, zoom and clickable teleport commands.

### Caster sentry source conflict

The archived roster labels its level-59 caster sentry **Thaumaturge** and lists
**Silver**. The saved [eLeMen key matrix](open_world_coffer_stronghold_sources.md)
identifies **Conjurer / Mythril**. Native sentry actor **2106472** uses the same
staff and body family as the Conjurer variants. This implementation follows
Conjurer/Mythril and records the conflict in
`Data/mobplacements/evidence/natalan-20260912/research.json`. It does not create
an extra Thaumaturge or a second Silver bearer from that conflicting row.

the existing **300-second** respawn policy and ranged attacks. Existing
nonzero custom HP/MP, nondefault respawn and detection settings are preserved.
Its wind/ice affinity and existing NM skill list remain intact.

Lozol and both guards have `linkGroup='natalan_lozol'`, fixed spawn centers,
and an empty `spawnGroup`. `WorldManager` adds all three to a `MonsterParty`;
using a spawn pool here would risk selecting only one actor. Guards use a
300-second respawn default. This implements the visible three-enemy group
through existing party behavior; special retail guard summoning, replacement
timing and encounter choreography are not reconstructed.

## Ground and density

The native outdoor transform is **MapNavi 3000**, base **(3712,2144)**, with
100 world units per map cell. Every spawn uses an exact point from
`Data/mobplacements/evidence/natalan-20260912/zone_143.tsv`:

- **8,247 recorded nodes / 4,930 captured edges**.
- SHA-256 `9495b7cd557a09405145897a3e2ab00eb4b5047cd738ca849bdfb07311bc9a4d`.
- **73** spawn points have nearby captured-edge support; **18** have two
  nearby recorded samples, explicitly labeled separately from captured edges.
- The independent premerge zone-143 snapshot was checked for coverage. Its
  IDs and edges were not merged into this recording; all new spawns use the
  single frozen current snapshot.

The reviewed map includes Natalan's northern entry, narrow upper passages,
lower enclosures and southern loop. Spawn centers use **14-yalm separation**
on comparable elevations, with **10 yalms** inside the boss/guard group.
Regular troops leave a **30-yalm pocket** around Lozol. Recorded floors more
than eight elevation units apart are considered separately for crowding.
Gate centers have eight yalms of clearance and other interactions twelve,
subject to the same elevation check. This is spawn-center spacing, not a
runtime no-entry boundary for combat or roaming.

Lozol's point is inside the historical **42,21 grid square** from the saved
eLeMen NM record, on the recorded upper slope. His two guards stay on that
upper slope; the lower Scarred Watchwolf uses its own lower recorded Y.
The main map and boss/guard crops were inspected. Exact XYZ, habitat spread
and density remain authored selections; map art is not proof of collision,
and recorded samples do not validate every future roam path. No new point
was marked as user-confirmed in the shared calibration results.

source nodes, support, hashes, levels and native appearances are pinned there.
Catalog spawn IDs are **963000–963090**, with **15 new BNPC profiles
39600–39614**. All bytes outside the three new marked SQL blocks were checked
against the pre-insertion catalogs and preserved.

```powershell
python -B tools/mobspawns/natalan.py build
python -B tools/mobspawns/natalan.py check
python -B tools/mobspawns/natalan.py render
python -B -m unittest discover -s tools/mobspawns -p test_natalan.py
```

The [Natalan migration](../Data/sql/live%20migrations/natalan_20260912.sql)
inserts missing profiles, new ordinary drops and placements with identity
guards. It preserves existing placements and drop chances, and repeated imports
do not duplicate rows. Existing schema/combat/Lozol loot data are prerequisites.
`Data/mobplacements/natalan/` contains the inspected provenance plans, capture
CSV and placement-only additive SQL. Use the full migration if the new profiles
and drop lists have not been imported; do not run the counter-based CSV converter.

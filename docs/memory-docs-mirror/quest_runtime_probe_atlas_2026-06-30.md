- `!questdelegate` proves a GM-only owner/method delegate smoke without quest state mutation; `class:<actorClassId>` resolves only one visible current-area actor and `@snpc5` expands path-companion payload rows.

- `!qciprobe` starts/updates QuestContentInformation, while `!qcifinish` proves success/fail/cancel direct numbers and ends the active QCI director.
- `!gcrivenroad acceptprobe normal|hard` proves the current-area guide-owned `askEnterInstanceRaid(15/16)` prompt result without starting content; the guide script recomputes the content id from the profile.
- `!testbnpckill` proves actor-class callback identity. It does not prove SQL stats, spawn placement, or private-content materialization.

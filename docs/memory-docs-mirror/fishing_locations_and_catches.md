# Fishing Locations and Catches from the FFXIV 1.x Wiki Archive

This document consolidates every `Fishing Items` table found in the local FFXIV 1.x wiki archive. It records 24 distinct catch-table locations from 19 region pages.

## Summary

- Source rows: **219**
- Rod-fishing rows: **155**
- Spear-fishing rows: **64**
- Distinct catch-table locations after consolidation: **24**
- Distinct rod catches: **56**
- Distinct spear catches: **20**
- Region pages containing catch tables: **19**

The wiki uses the term **Fishing Items**, not strictly *fish*. Its tables also include shellfish, kelp, coral, frogs, turtles, bait-like creatures, dyes, muddy water, and several types of matter. The lists below preserve that broader wiki classification.

Only four of the 155 rod rows have a non-empty `Skill` cell. Each is a type of matter and requires **Fingerprints of the Gods**:

| Location | Catch | Grade | SS | Skill |
|---|---|---:|---:|---|
| Bloodshore | Calcified Matter | 3 | -5 | Fingerprints of the Gods |

All 155 rod rows have an `SS` value ranging from -5 through 4, but the examined archive pages do not define the abbreviation. All fishing-table `Notes` cells are empty. This document therefore reports the exceptional `SS = -5` skill-bearing rows above without assigning an unsupported meaning to `SS`.

## Source-data decisions and caveats

- **Blank locations:** 21 source rows have an empty `Location` cell: Gridania (6), Limsa Lominsa (5), Mistbeard Cove (5), and Ul'dah (5). For these rows, this document uses the containing region page as the location.
- **Black Brush duplication:** Black Brush appears on both the Central Shroud and Central Thanalan pages. The Central Thanalan page supplies all six rod catches and seven spear catches. The Central Shroud page adds Allagan Snail and All-purpose Purple Dye as spear catches. This document consolidates the union under one Black Brush entry while retaining both source regions.
- **Exact spelling:** `Cretified Matter` is not a transcription error in this document. Both the item text and link title use that spelling in the East Shroud source page. `Calcified Matter`, `Cultured Matter`, and `Ossified Matter` are separate source entries.
- **Counts shown by the wiki:** A page heading such as `Fishing Items (16)` counts unique catches separately within each method. It does not necessarily equal the number of table rows because the same catch may appear at multiple locations on the page.
- **No inferred mappings:** The separate named `Fishing Holes` records and Fisher levequest records are reported, but no catch list is inferred for them because the local wiki pages do not make that connection.

## Verification

The extraction was checked three ways:

1. A full recursive search of the local wiki found exactly 19 HTML pages containing `Fishing Items`/`Rod Fishing` catch tables. No catch tables were found elsewhere in `pages`, `bestiary`, CSV, or Markdown files.
2. A direct table extraction found 219 rows: 155 rod rows and 64 spear rows. Consolidating the explicit `Location` cells plus the four blank-location page fallbacks produced 24 locations.
3. A second extraction using an independent HTML parser reproduced the same 219 rows and counts. For all 19 pages, the parsed unique-catch totals per method exactly match the number displayed in the page's `Fishing Items (N)` heading.

The special spellings, all 21 blank locations, the Black Brush cross-page duplication, and the separate `Fishing Holes` pages were also checked directly in their source HTML.

A final metadata pass confirmed that all 219 rows have a location grade, that grades are consistent within each consolidated location, that exactly four rod rows contain a skill requirement, and that every fishing-table `Notes` cell is empty.

An additional pass checked the Fisher class page and nearby levequest listings. Those pages list Fisher leve names and leve locations, but no additional `Fishing Items`, `Rod Fishing`, `Spear Fishing`, or item-to-location catch mappings.

## Command Order

1. `!questdelegate` and `!questevent`
   `!questevent` is the C# recorder and `!questdelegate` is the no-mutation Lua/director smoke runner. Use them together to capture owner/event/type/function behavior before route edits.

2. `!sqbprivate`
   Implemented as a Lua GM probe for spawn-ready private fight smokes. Rewards, blocked actor-data rows, and high-fidelity materialization remain locked until exact retail proof exists.

3. Toto-Rak and Dzemael legacy occupancy probes
   Toto-Rak mostly needs Lua arg plumbing. Dzemael now uses `!occupancyduty` probe-only `dutycs` from the existing occupancy profile, but not production lifecycle yet.

4. `!instanceraid` and `!gcrivenroad`
   Modern instance raids start with allowlisted `scene=none` probes. Rivenroad starts with guide-owned `acceptprobe normal|hard` confirmation probes; replay scenes are not launch proof.

5. `!qcifinish`
   Implemented now as a low-risk QCI finish/fail/cancel validation command against existing `QuestContentInformationDirector` profiles.

## Safety Rule

The active event owner is the NPC, object, or director. The quest is only the delegated target. Every cutscene proof must capture owner, event type, wrapper method, typed args, result tuple, quest state before/after, and close timing.

Scene render success is not quest proof. For fights, `!testbnpckill` is callback-only; `!sqbprivate` must prove private content, materialization, kill callback, return, cleanup, and reward lock before enablement.

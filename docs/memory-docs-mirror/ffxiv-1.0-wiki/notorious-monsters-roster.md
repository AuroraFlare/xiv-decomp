## Source priority

- eLeMeN wins whenever it explicitly publishes a field: location, spawn condition, family, weaknesses/resistances, breakable parts, mechanics, moves, and eLeMeN-listed loot.
- Local canonical server/capture data supplies runtime-only values and captured coordinates; eLeMeN does not publish level, HP, MP, or numeric combat stats on these NM pages.
- The Kai guide is a fallback/supplement for fields still absent from both sources.
- Gamer Escape category membership proves historical roster membership, not a numeric or runtime value.

# Primal Special Actions

- Enemy type: Undocumented
- Source: https://web.archive.org/web/20130509205503/http://ffxiv.gamerescape.com/wiki/Category:Primal

| Action | Description |
| --- | --- |
| Aerial Blast | Calls upon the primal force of wind, dealing massive damage to all foes within range. Damage can be reduced by hiding behind terrain. |
| Crimson Cyclone | Leap forth into the air, then dash towards enemies, setting them ablaze. |
| Downburst | Deals Wind damage to a target. |
| Eruption | Cause the earth beneath the target's feet to shatter, unleashing gouts of flames beneath them. |
| Featherlance | Explode in a burst of wind, damaging foes and terrain alike. |
| Hellfire | Summon forth spires of concentrated fire, then unleash a hellish blast, dealing massive damage to all within range. |
| Incinirate | Spew forth Fire from the mouth, damaging enemies in a frontal cone. |
| Mistral Shriek | Calls upon the gales to vanish and reappear elsewhere, unleashing a razor wind through foes. Can be blocked by terrain. |
| Mistral Song | Calls upon the gales to vanish and reappear elsewhere, unleashing a razor wind through foes. Can be blocked by terrain. |
| Plumage | Summons forth Razor Plumes. |
| Radiant Plume | Sear the very earth, causing great gouts of lava to plume forth dealing massive damage. |
| Sear | Let forth a cloud of burning ash damaging those in a small area. |
| Slipstream | Unleash a gale upon a foe, stunning them and dealing Wind damage. |
| Vulcan Burst | Let forth a wave of Fire damaging and knocking back foes within range. |
| Wicked Wheel | Release a scything wind, knocking back and damaging all foes within range. |

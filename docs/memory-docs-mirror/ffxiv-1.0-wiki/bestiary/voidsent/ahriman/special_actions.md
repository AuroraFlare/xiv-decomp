# Ahriman Special Actions

- Enemy type: Voidsent
- Source: https://web.archive.org/web/20130510035953/http://ffxiv.gamerescape.com/wiki/Category:Ahriman

| Action | Description |
| --- | --- |
| Aural Vacuum | Inflicts area of effect damage. |
| Death March | Unleash a burst of Umbral energy, damaging all targets within an area of effect. |
| Death Throes | Releases a burst of enervating darkness, Binding, Silencing, Pacifying, and causing Amnesia to targets within an area of effect. |
| Level 5 Petrify | Petrifies all targets with levels in multiples of 5 |
| Seismic Scream | Ranged attack that inflicts earth damage. |

# Bomb Special Actions

- Enemy type: Voidsent
- Source: https://web.archive.org/web/20130509235040/http://ffxiv.gamerescape.com/wiki/Category:Bomb

| Action | Description |
| --- | --- |
| Combustion | User self destructs, dealing massive Fire damage to all caught in the blast. Power varies based on remaining life of user. Used after a bomb has expanded in size several times. |
| Explosion | User unleashes accumulated power as energy, damaging all targets. Does NOT kill user. |

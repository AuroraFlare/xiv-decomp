# Ogre Special Actions

- Enemy type: Voidsent
- Source: https://web.archive.org/web/20130509235036/http://ffxiv.gamerescape.com/wiki/Category:Ogre

| Action | Description |
| --- | --- |
| Bone Breaker | Crush an enemy, dealing massive damage and knocking them back. |
| Booming Bellow | Let out a booming roar, Stunning targets and resetting their hate. |
| Double Smash | Enemy deals a powerful blow, composes itself, and then deals another. |
| Elbow Drop | Sensing party members attacking from behind, the enemy delivers a conal aoe in their direction. |
| Firespit | Enemy sprays from the mouth, dealing Fire damage to all in range. |
| Inferno Drop | The enemy leaps into the air and crashes to the ground, sending powerful fire damage in all directions. |

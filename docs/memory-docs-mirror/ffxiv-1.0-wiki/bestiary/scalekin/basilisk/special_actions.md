# Basilisk Special Actions

- Enemy type: Scalekin
- Source: https://web.archive.org/web/20130510002504/http://ffxiv.gamerescape.com/wiki/Category:Basilisk

| Action | Description |
| --- | --- |
| Body Slam | Jump up into the air, slamming into the ground, damaging and weighing down enemies within area of effect. |
| Cold Glare | User's eyes glow, paralyzing all who meet its gaze with paralysis. |
| Heavy Stomp | Trash about violently, damaging foes within a frontal cone. |
| Sand Breath | Exhales a large burst of sand, damaging targets in front of user. |
| Vorpal Roar | Uses a sharp roar to injure a distant opponent |

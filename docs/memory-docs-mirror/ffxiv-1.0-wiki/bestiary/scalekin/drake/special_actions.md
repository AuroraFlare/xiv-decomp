# Drake Special Actions

- Enemy type: Scalekin
- Source: https://web.archive.org/web/20130509083146/http://ffxiv.gamerescape.com/wiki/Category:Drake

| Action | Description |
| --- | --- |
| Burning Cyclone | User spins violently while breathing fire. |
| Caudal Spine | Launches a spine from the tail at target. |
| Flames of Defiance | User breaths powerful flames |
| Land Scorch | User exhales lightning breath. |
| Serpentine Tail | User strikes a target behind it with its tail. |
| Smoulder | Causes the user to glow with a fiery aura and adds fire damage to user's attacks. |
| Surge | Adds Thunder element to attacks, User glows purple |

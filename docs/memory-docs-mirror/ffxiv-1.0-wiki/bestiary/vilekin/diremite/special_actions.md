# Diremite Special Actions

- Enemy type: Vilekin
- Source: https://web.archive.org/web/20130510002526/http://ffxiv.gamerescape.com/wiki/Category:Diremite

| Action | Description |
| --- | --- |
| Caustic Blow | Deals damage and inflicts a target with Defense Down. |
| Deadly Thrust | Users stabs target with tail, inflicts poison. |
| Sticky Web | Sprays webbing over a large area, slowing all caught in the web. |

# Gnat Special Actions

- Enemy type: Vilekin
- Source: https://web.archive.org/web/20130510000917/http://ffxiv.gamerescape.com/wiki/Category:Gnat

| Action | Description |
| --- | --- |
| Brundleflight | Gnat moves at lightning speed and reappears in a random location around the target. |
| Shockbreath | Unleashes a burst of lightning, damaging all foes within a cone. |
| Thunderstrike | Gnat blasts an electrical stream at an opponent. |

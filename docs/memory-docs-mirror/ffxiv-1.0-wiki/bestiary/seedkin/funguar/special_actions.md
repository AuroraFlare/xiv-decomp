# Funguar Special Actions

- Enemy type: Seedkin
- Source: https://web.archive.org/web/20130510000829/http://ffxiv.gamerescape.com/wiki/Category:Funguar

| Action | Description |
| --- | --- |
| Hypha Whip | User spins arms, damaging and slightly knocking back all foes in range. |
| Queasy Cloud | Inflicts Poison and damage to targets within Area of Effect. |
| Slumber Cloud | Releases a cloud of spores, putting targets within range to Sleep |
| Slumber Spores | Fires spores at a target, putting them to Sleep. |

# Treant Special Actions

- Enemy type: Seedkin
- Source: https://web.archive.org/web/20130510040032/http://ffxiv.gamerescape.com/wiki/Category:Treant

| Action | Description |
| --- | --- |
| Arboreal Storm | Lash out with roots, striking all targets within range. |
| Canopy | Shed and regrow leaves, removing harmful status effects. |
| Pinecone Bomb | Launch a pinecone, damaging a distant foe. |
| Switch Swipe | Slash foes in front of you with branches. |

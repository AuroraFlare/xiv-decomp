# Cactuar Special Actions

- Enemy type: Seedkin
- Source: https://web.archive.org/web/20130510002634/http://ffxiv.gamerescape.com/wiki/Category:Cactuar

| Action | Description |
| --- | --- |
| 1,000 Needles | Deals 1,000 points of damage divided among all targets in rage. |
| 1000 Needles | Fires forth a thousand needles, damaging targets within area of effect. |
| Sun Spines | Fire off a burst of needles, damaging and Binding everyone within range. |
| Tender Thrust | Lunge at an enemy, damaging them and knocking them back. |

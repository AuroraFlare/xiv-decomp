# Vanguard Special Actions

- Enemy type: Forgekin
- Source: https://web.archive.org/web/20130509212121/http://ffxiv.gamerescape.com/wiki/Category:Vanguard

| Action | Description |
| --- | --- |
| Cermet Drill | Cuts forth into an enemy, damaging them and resetting their enmity. |
| Drill Cannon | Launches drills at a target, damaging them and knocking them back. |
| Overcharge | Power coils overload, Stunning and dealing heavy Lightning damage to foes within an area of effect. |

# Mole Special Actions

- Enemy type: Beastkin
- Source: https://web.archive.org/web/20130509082948/http://ffxiv.gamerescape.com/wiki/Category:Mole

| Action | Description |
| --- | --- |
| Breakout | Burrows underground and then strikes at a target area from below. |
| Spin Out | Hedgemole burrows underground, and emerges several seconds later, somersaulting out of the ground, and launching a spine at its target. |

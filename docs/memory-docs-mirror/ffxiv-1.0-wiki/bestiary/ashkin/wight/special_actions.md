# Wight Special Actions

- Enemy type: Ashkin
- Source: https://web.archive.org/web/20130505013853/http://ffxiv.gamerescape.com/wiki/Category:Wight

| Action | Description |
| --- | --- |
| Doomwave | Deals Umbral damage to a target at range. |
| Minions of the Pit | Release a burst of Umbral energy, damaging foes and feigning one's own death |
| Shadow Sickle | Deals Umbral damage to targets in an area of effect. |
| Soul Eater | Sends out a void of Umbral energy, absorbing health of targets within a cone. |

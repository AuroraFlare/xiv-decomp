# Vulture Special Actions

- Enemy type: Cloudkin
- Source: https://web.archive.org/web/20130510002744/http://ffxiv.gamerescape.com/wiki/Category:Vulture

| Action | Description |
| --- | --- |
| Deafening Caw | Resets all TP to 0 of all in area of effect |
| Feather Flurry | User shoots feathers at target from a distance |
| Wing Cutter | User slashes the air with wings damaging all opponents before them. |
| Yolk Shower | Inflicts area of effect damage |

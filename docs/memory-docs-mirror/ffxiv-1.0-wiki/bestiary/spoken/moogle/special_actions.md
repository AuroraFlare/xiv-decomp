# Moogle Special Actions

- Enemy type: Spoken
- Source: https://web.archive.org/web/20130509235054/http://ffxiv.gamerescape.com/wiki/Category:Moogle

| Action | Description |
| --- | --- |
| Break | Entomb a target in stone, petrifying them. |
| Cure IV | Sooth a target's wounds with white magic. |
| Maximoogle | Cause a target to puff up in size, granting them immunity to damage, but a reduced movement speed. |
| Memento Moogle | Summons forth a burst of kupotastic energy, damaging all enemies within range. Damage varies with the number of surviving moogles. |
| Mogdive | Rush forward, slamming into a target. |
| Mognesia | Sprays forth an umbral mist, befuddling the mind of spellcasters. |
| Moogle-Go-Round | Spin around with a blade, cutting all enemies within range. |
| Moogle Eye Shot | Take aim on a target, striking their vital points with an arrow. |
| Pom Flare | Release a burst of umbral energy, harming all enemies within range. |
| Whisker Bash | Slash an opponent with razor sharp whiskers, rendering them incapable of using weapon skills. |

# Enemy Humanoid Special Actions

- Enemy type: Spoken
- Source: https://web.archive.org/web/20130509211741/http://ffxiv.gamerescape.com/wiki/Category:Enemy_Humanoid

| Action | Description |
| --- | --- |
| Attrition | Strikes all foes within range. |
| Fierce Ravensbeak | Teleport to a foe, slaying them instantly. |
| Iron Chariot | Damage and knock back foes within an Area of Effect. |
| Lunar Dynamo | Drains HP and MP from distant foes. |
| Megaflare | Calls forth Dalamud's power, summoning forth a swarm of meteors, ending in a massive explosion. Damage may be reduced by destroying Lunar Fragments. |
| Ravensbeak | Damage and stun a foe. |
| Thermonic Beam | Teleport to the other side of the battlefield, firing forth a beam of energy at foes. |
| Twisting Vice | Stab and twist, dealing piercing damage and reducing the target's TP. |

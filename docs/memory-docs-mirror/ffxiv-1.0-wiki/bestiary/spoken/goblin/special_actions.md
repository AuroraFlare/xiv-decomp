# Goblin Special Actions

- Enemy type: Spoken
- Source: https://web.archive.org/web/20130510035921/http://ffxiv.gamerescape.com/wiki/Category:Goblin

| Action | Description |
| --- | --- |
| Bomb Toss | Deals Fire damage to the target and allies within an area of effect. Short fuses may cause mishaps, leading to self destructs. |
| Firecracker Shower | User tosses a handful of firecrackers into the air, stunning all targets around user. |
| Hail Mary | Deals Single Fire Target Damage. Goblin lobs a bomb high into the air. Bomb falls and lands on target approximately 15 to 30 seconds later. |

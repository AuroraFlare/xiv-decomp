# Ixal Special Actions

- Enemy type: Spoken
- Source: https://web.archive.org/web/20130509125532/http://ffxiv.gamerescape.com/wiki/Category:Ixal

| Action | Description |
| --- | --- |
| Sunset Plumes | Unleashes a barrage of feathers, damaging and Blinding foes within range. |
| Swift Gust | Calls forth a gale to raise evasion. |
| Updraft | Deals Wind damage to targets within an area of effect. |
| Wind Claw | Slash the air, creating a gale that cuts through foes at range. |

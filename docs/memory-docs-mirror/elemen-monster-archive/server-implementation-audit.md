## Evidence boundaries

- Crystal data is an affinity/order, not a shard/crystal/cluster tier or rate table.
- eLeMeN does not publish numeric enemy move potency in these archive files.
- Existing numeric potency is preserved except for 100/1,000 Needles, whose exact shared totals were already implemented in `BattleUtils`.
- Knockback/draw-in use client hit flags plus server-authoritative, navmesh/object-collision-clamped movement; the 4-yalm Level 1 knockback distance is explicit server policy because eLeMeN supplies no magnitude.
- eLeMeN does not publish the numeric NM attributes stored in `server_enrichment`; those values are local server data and are reported separately.
- Idle HP regeneration is intentionally outside this implementation pass.

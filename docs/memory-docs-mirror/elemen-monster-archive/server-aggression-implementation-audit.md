## Policy boundaries

- The common 15-yalm detection range is server policy; eLeMeN publishes the sense category, not a numeric range.
- The 65% smell/low-HP runtime threshold is server policy; it is not claimed as a recovered retail constant.
- Passive rows retain their sourced detection sense and 15-yalm range, while `isHostile = 0` prevents ambient aggro.
- Mixed-family variants with ambiguous species identity receive a uniform sourced family sense/range while preserving their local hostility flag.
- Unknown source senses preserve the pre-existing detection type and receive the 15-yalm range so hostile rows can use the existing Sight fallback.
- The eight open-world humanoid Sight rows are project-owner-confirmed supplements, kept distinct from the eLeMeN-derived rows in canonical SQL data and audit evidence.
